# Дополнительный swap после v0.3.4 Preview

При новой установке этап настройки IPv6 и BBR/FQ дополнительно пытается создать `/swapfile` размером 2 ГиБ. Перед созданием он требует не менее 4 ГиБ свободного места в корневой файловой системе: 2 ГиБ для файла и 2 ГиБ остаются для установки. Если места меньше, swap пропускается без ошибки.

Установщик использует `fallocate`, устанавливает права `0600`, запускает `mkswap` и `swapon`, а затем добавляет одну строку `/swapfile none swap sw 0 0` в `/etc/fstab`. Повторное применение не создаёт дубликатов. Существующий чужой `/swapfile` не удаляется и не заменяется; несовместимый файл или запись в `fstab` останавливают этап до настройки IPv6 и BBR. Preflight только читает состояние. При ошибке создания включённый swap выключается, а созданный файл и проектная строка восстанавливаются.

Изменение сделано после опубликованного тега `v0.3.4`; опубликованные assets v0.3.4 его не содержат. Проверены unit/mock-тесты, но установка swap и reboot на VPS пока не проверены.
