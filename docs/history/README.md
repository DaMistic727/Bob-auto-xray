# Исторические acceptance results

Основные актуальные ссылки находятся в `docs/reference-*.json`. Этот каталог сохраняет ранние результаты без переписывания их под более новые версии проекта.

`v0.1.0-ubuntu-24.04/` содержит опубликованные при первом релизе результаты среды Ubuntu 24.04 amd64 с PHP 8.3 и тогдашним набором acceptance checks. Они подтверждают только описанный в самих файлах прогон v0.1.0 и не являются доказательством поведения v0.3.x, Ubuntu 26 или TCP BBR.
