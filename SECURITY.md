# Сообщение об уязвимости

Не публикуйте exploitable детали, credentials, реальные UUID/ссылки подписок, private keys и дампы базы в открытых Issues.

Сообщить приватно: [GitHub Security Advisories → Report a vulnerability](https://github.com/DaMistic727/Bob-auto-xray/security/advisories/new).

Укажите версию релиза, затронутый компонент, условия воспроизведения и последствия. Удалите персональные адреса и секреты из примеров. Если приватная форма недоступна, откройте Issue только с просьбой предоставить канал связи, без подробностей уязвимости.

## Поддерживаемые версии

Проект находится на стадии preview. Исправления вносятся в текущую ветку `main`; для установки используйте последний проверенный versioned release. Автоматическое обновление установленных серверов не реализовано.

## Модель доверия

Bootstrap получается из конкретного GitHub release по HTTPS. SHA256 payload закреплён внутри bootstrap и проверяется до распаковки. Это защищает от повреждения и неожиданной подмены payload относительно выбранного bootstrap; целостность самого bootstrap зависит от доверия GitHub-аккаунту и каналу его получения. SHA256, скачанный рядом с файлом, не является независимой подписью автора.

Xray, 3x-ui, GeoData, профили и WARP keyring закреплены в `versions.lock.json` (SHA256). Исключение: VPS-Server-Menu (режим WARP install/adopt) берётся из актуальной официальной `main` во время установки и не закреплён; фактическая ревизия сохраняется в root-only state `menu_revision`. Системные пакеты поступают из подписанных APT-репозиториев. Проверки установки останавливаются при ошибке; неизвестные каталоги и чужие конфигурации не удаляются.
